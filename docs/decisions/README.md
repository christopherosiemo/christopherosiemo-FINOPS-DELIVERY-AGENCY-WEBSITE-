# Architectural decision records

ADRs preserve consequential decisions and their trade-offs without turning routine implementation details into ceremony.

Use a numbered Markdown file with: status, context, decision, and consequences. Add an ADR when a choice is costly to reverse, changes a cross-cutting boundary, or prevents recurring debate. Update or supersede an ADR; do not silently rewrite its history.

- `0001-next-app-router.md`: application architecture.
- `0002-css-tokens.md`: styling and token architecture.
- `0003-testing-strategy.md`: layered testing strategy.
