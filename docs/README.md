# Project documentation

This directory is the durable context for product and website work. Read the documents relevant to a change before implementation; do not replace unknowns with invented requirements.

- `PRODUCT.md`: proposition, offers, operating model, and commercial boundaries.
- `BRAND.md`: MEASURED doctrine, voice, and prohibited claims.
- `DESIGN_SYSTEM.md`: working visual and motion primitives.
- `INFORMATION_ARCHITECTURE.md`: known routes, hierarchy, and TBD content structure.
- `ENGINEERING.md`: implementation rules and local workflow.
- `ACCESSIBILITY.md`: WCAG target and foundational practices.
- `PERFORMANCE.md`: rendering principles and future budgets.
- `ANALYTICS.md`: measurement principles and unresolved implementation choices.
- `SECURITY_BOUNDARIES.md`: current trust boundaries and prohibited data handling.
- `QUALITY_GATES.md`: the 0–100 delivery programme.
- `PROGRESS.md`: current gate status and evidence.
- `decisions/`: lightweight architectural decision records.
